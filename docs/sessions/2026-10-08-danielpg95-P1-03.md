## Problems and findings

- The timer needs the Raster's `requestId`, which only the `ui.render` hook sees (`e.requestId`). The render hook stores it and starts the timer once, and stops it when the band hides the encounter.
- The validator only accepts `$` passed to functions declared at the top of the module, so the timer helpers and their state are module-level (reset on reload, as the module loads fresh).
- A blit still in flight makes the next tick skip, so frames never queue.
- Timers stop on `turn.complete`, `session.end`, when the encounter hides, and on reload (per DEVELOPMENT.md). The user's manual run did not test reload separately.
- The first manual attempt showed nothing because `--plugin-dir` was run from a checkout that did not contain the spike folder.
