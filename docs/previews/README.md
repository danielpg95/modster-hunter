# Modster previews

One image per built-in Modster: its sprite enlarged, every frame, on a dark row
and a light row. PRs that add or change a Modster embed these in their
description (see the PR template). Regenerate a preview whenever its sprite
changes.

`catchers/` has one GIF per built-in catcher (decision 0035): its throw on
Shellsprout at 4×, 12 fps. From left: a catch, a miss after 2 rocks and a miss
after 1, each on a dark terminal and then a light one. They are drawn with the
mod's own `catchFrame`.
