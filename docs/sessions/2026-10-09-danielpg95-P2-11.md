## Decisions made

- The cap constant is `ENCOUNTER.agentWorkMaxMs`, not a top-level `AGENT_WORK_MAX_MIN`, to match `constants.ts` (Claude).
- A subagent start does not reset an encounter's idle timer; only a turn start does (0005 unchanged; Claude).
- If the countdown passes due while work is running but no tick lands before the work stops (e.g. a lost agent past its cap), the Modster appears at the next work start, as turns already behaved (Claude).
