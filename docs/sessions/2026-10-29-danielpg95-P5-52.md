## Problems and findings

- Presses that don't reach a mod show in
  `~/Library/Logs/Claude/claude.ai-web.log` as `engine surface: ui_press not
  handled`, with the Button's key. That is how rounds 1–4 were debugged.
- A `Markdown` with `onLinkPress` takes the handlers away from every Button
  drawn after it in the same tree. Round 1 blamed the Client; round 3 (Client
  off) ruled it out; round 4 (Markdown last) fixed it.
- A pane with 35 thumbnails (678,175 characters of Svg) is refused on redraw:
  the old drawing stays and every Button goes dead. 12 (209,750) work.
- A hooks module file is read only up to 1 MiB.
- `/reload-plugins` with a mod's pane open leaves the pane blank ("nothing to
  show yet"); a new session draws it.
- The game's band hook answers without `next(e)` while hunting, so another
  mod's band row never draws. With the game off, the spike's band row draws
  and its Poke reaches the mod.
- A Button over an Svg (`position: absolute`) works; an Svg itself can't be
  pressed, and an `isInteractive` one runs SMIL clicks the mod never hears.
- The terminal was unchanged with the spike installed.
- No screenshots were taken; the README has the findings in words.
