## Problems and findings

- The test engine in Claude Code 2.1.296 has no `$.ui.close` or `$.ui.open` on the test's `$` (only `render`, `scroll`, `focus`, `press`, `input`, `select`, `mount`), so a test can't raise a close with origin `person`. The close rule lives in the pure `prefAfterClose` and is unit-tested; the hook only checks the pane id.
- `e.origin` on `ui.close` is an object, `{ kind: 'person' | 'plugin' | 'unload' }`, not a string. `tsc` caught a first version comparing it to `'person'`, which would never have matched.
