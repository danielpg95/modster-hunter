## Problems and findings

- A `Raster` cell is three uint32 values `[codePoint, fg, bg]`; `0x01000000` is the terminal default. `Uint8Array#toBase64()` works in the mod runtime and in `claude plugin test`.
- A transparent top half must be `▄` (fg = bottom pixel, bg default). `▀` with a default foreground paints the terminal's text color.
- Largest sprite: 14 px tall at 80×24 (`maxRows` 7), 30 px at 120×40 (`maxRows` 15). Recorded in 0001 with a 12×12 authoring size.
- `Raster` is not in the element table for the Desktop surface, so the hook returns `next(e)` unless `e.surface === 'terminal'`.
- `claude-code/testing` is the test import (`test`, `expect`); `Uint8Array.fromBase64` needs a cast in the test for the typings.
