## Decisions made

- Delete is handed to the `create-modster-content` skill, because `$.fs` has no
  delete and a process call would break golden rule 7 (@danielpg95, 0032).
- Disabled items stay in their own tab, dimmed and marked `off` (@danielpg95, 0032).
- Drafted by Claude within 0032: the key is `o`; an uncaught Modster's toast
  says "That Modster"; turning off the last biome is allowed (0031 point 4
  covers it).

## Problems and findings

- The engine refuses to load the module when `$` is passed to a `const` inside
  `register`'s closure ("$ is passed to "toggle", which is not a function
  declared at the top of this file"). Helpers that take `$` must be top-level
  function declarations.
- `pane.press` waits for the async work an `onPress` starts (fs reads and
  writes, the reload), so adapter tests need no polling.
- Turning off a Modster that's a biome's only one drops that biome, which can
  move the session to another biome.
