## Done

- **Decision 0015** (supersedes 0008): user Modsters may set `sprite.file` to a
  `.png` with a new `sprite.frames` (1–8). The decoder reads RGB/RGBA at 8 bits
  and palette PNGs at 1/2/4/8 bits. The cache is in
  `~/.claude/modster-hunter/cache/sprites/`. CONTENT_FORMAT, ARCHITECTURE and
  DEVELOPMENT are updated to match.
- `plugin/hooks/vendor/inflate.ts`, `png.ts`: moved from the spike and
  rewritten on `Uint8Array` with an output cap. The size limits are checked
  before inflating, and unsupported variants throw `UnsupportedPngError`. The
  spike's `lib/` was deleted.
- `plugin/hooks/content/`:
  - `sprite-from-png.ts`: decodes a sheet, then runs `spriteFromSheet`; an
    unsupported PNG's error points to `tools/sprite.mjs`.
  - `cached-sheet-loader.ts`: the cache is used when size, mtime and frames
    all match and the sprite still validates. A failed cache write is ignored.
  - `validate-settings.ts`: validates the user `settings.json`.
  - `merge-content.ts`: the user replaces built-ins by id, then the disable
    lists apply (an unknown id is a warning), then references are checked.
  - `load-all-content.ts`: built-in plus user folder, `includeBuiltins`, and
    the settings file.
  - `no-biomes-message.ts`: the message shown when no biome is left.
- `load-content.ts`:
  - `loadFolder` no longer checks references; `resolveReferences` runs after
    merging, so a user biome can list built-in Modsters.
  - User issues are labelled `~/.claude/modster-hunter/content/…`.
  - `LoadedBiome` gains a `file` field.
- `register.tsx`:
  - The home folder comes from `$.env.get('HOME')`, or `USERPROFILE`.
  - `sheetFiles` is the PNG cache's file port, built from `$.fs`.
  - With zero biomes, the mod shows one toast at session start, and the same
    text comes back from `/modsters`.
- Tests (327 total) cover: inflate (every block type, cap, cut-short),
  png (Pillow 1/2/4/8-bit and pngjs fixtures match pngjs pixel for pixel,
  every filter, unsupported variants), and settings, merge, cache, load-all,
  PNG loading and register (user PNG biome, cache written, both no-biome messages).
- Verified: typecheck clean; `claude plugin test` 327 pass;
  `validate --strict` passes; `test:tools` 12 pass; `check:content` passes.
  `claude --plugin-dir ./plugin -p "/modsters"` → "You're in Whispering Forest".
