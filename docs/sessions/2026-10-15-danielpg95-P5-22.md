## Goal for this session

Turn the reference-image approach that lifted the P5-19 sprites into a repo
tool and a documented workflow, so every contributor gets the same quality
and style.

## Done

- `tools/ref-sprite.mjs` (`npm run ref-sprite`): cuts the background away
  along the reference's dark outline (flood fill from the crop's edges,
  `--edges` to skip an edge the subject touches, `--dark` threshold), builds a
  ≤ `--colors` palette by k-means, shrinks to `--size` by majority color per
  cell, keeps the largest shape, writes a PNG and optionally a letter grid;
  `--from-grid` rebuilds a PNG from an edited grid. Logic is in exported pure
  functions.
- `tools/ref-sprite.test.mjs`: 9 tests on a synthetic outlined creature
  (cut-out, edge option, palette, shrink keeps outline and eye, stray specks,
  grid round trip and errors, CLI happy path and bad arguments, transparency).
  `npm run test:tools`: 32 pass.
- `add-modster` skill: step 3 prefers the reference path; a new "From a
  reference image" section with the prompt template (house style), keeping
  references out of the repo, conversion, a hand-finishing checklist, and
  animation tips. The reference-image rule now separates the contributor's
  own reference (convert as is) from other images (ideas only).
- `docs/DEVELOPMENT.md` lists the command and explains it.
- Checked by hand on the P5-19 Elderbark reference: 55×33, the amber eyes
  survive, and a grid round trip gives the same PNG.

## Decisions made

- Input is PNG only; no JPEG decoder dependency. The skill gives the
  one-line conversion. (@danielpg95 chose "skill + conversion tool".)
- Credits name the contributor as the artist and don't name the tool used to
  make the reference (@danielpg95, 2026-10-14).

## Problems and findings

- A subject that touches the reference's edge makes the flood fill leak into
  it; `--edges` covers that (Elderbark's canopy ran off the top).
- Averaging blurs thin dark lines; majority color per cell keeps them. Heavy
  outlines in a detailed reference still shrink into black blobs, which is
  why the finishing step exists.
