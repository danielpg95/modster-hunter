## Problems and findings

- Plugin options can't be multi-select: only boolean, number, or a string with `options` (a picker). Any change in `/config` reloads the module.
- Spinner rows carry the agent id as `requestId`. Subagents are told apart by matching it against the machine's agents. Whether the main spinner's id is ever in that list hasn't been checked in a real session.
- In the status line, the appearing phase reads `A wild X (tier) appeared!`, since Throw isn't available yet (0014). From waiting on, it uses the 0023 format. With the pane `off`, it says `1: Throw in the band`.
- In tests, the `session.end` stub must return `{ sessionId }` and the `ui.close` stub must return `{ value }`.
