## Problems and findings

- Generated art may have parts with no dark outline (Mossmaul's moss). The
  outline cut-out leaks through those, so cut by the plain background's
  colour instead (`--edges none --clear`).
- Extra poses are different drawings: use them for parts (closed eyes), not
  whole frames.
- Browsers shift an embedded image's colours slightly, so exact colour
  matching in SVG filters is unreliable. Anything colour-specific is found at
  load time from the decoded PNG.
- A local static page can't be screenshot in the browser pane; a small local
  HTTP server (`python3 -m http.server`) lets it render and be checked.
