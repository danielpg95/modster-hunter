## Decisions made

- Use a bundled Node helper, not the runtime path alone or GIF decoding in the
  mod (@danielpg95). Drawn art is written as a PNG sheet, not a `.sprite.json`.
  The helper runs the mod's own validator for checking.
- Extend the PNG decoder to every PNG (option a in 0025) (@danielpg95).
- Grid format for `draw`: `palette` of one-character keys (`"transparent"`,
  `#rrggbb`, `#rrggbbaa`) and `frames`, lists of equal rows (accepted when
  @danielpg95 said to finish P4-06). It belongs to the helper, not the content
  format.
- `check` takes `--without-builtins`, since the helper can't read the user's
  `includeBuiltins` option.

## Problems and findings

- pngjs's *writer* mangles 8-bit input when asked for 16-bit gray, and its
  reader then agrees with that file. Tests build 16-bit PNGs with
  `plugin/tests/fixtures/encode-png.ts` instead.
- Pillow interlaces a GIF only when it's at least 16 px tall.
- The helper hasn't been run against a real installed plugin copy. Paths are
  relative to the script, so it should work wherever `plugin/` is copied.
