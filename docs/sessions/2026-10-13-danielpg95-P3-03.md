## Problems and findings

- `pane.find({ type: 'Text', key })` doesn't find a Text by its key in the test
  engine. Read the parent Box instead (the header test does).
- The session's biome is random, so the "opens on the session biome" test reads
  which one from the header and checks that one.
- The built-in scenes are 6 rows, so an inline pane (about 5 rows for the tab)
  never shows one. A docked pane does.
- The test engine can't raise `ui.close`, so stopping the scene on close was
  checked by hand.
